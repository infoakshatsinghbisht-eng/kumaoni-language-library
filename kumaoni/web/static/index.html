अखाण (Traditional Kumaoni Proverbs)

गौंक जोगी जोगना, आन गौंक सिद्ध।
Gaunk jogi jogana, aan gaunk siddh.

Meaning: Familiarity breeds contempt; people rarely honor local talent.

Hindi Parallel: घर की मुर्गी दाल बराबर।

English Parallel: A prophet is never honored in his own country.

आणा (Kumaoni Riddles)

लाल गाय पाथर खाए, पाणि पिबे तो मरी जाए।
A red cow that eats wood/stones, but dies if it drinks water. What is it?
उत्तर: आग (Fire)

Developer SDK & Code Recipes

Designed to be as intuitive as Python's built-in math library for your apps, APIs, and NLP pipelines.

Python 3 • kumaoni_app_example.py 
import kumaoni

# 1. Translate from any world language directly to Kumaoni
res = kumaoni.translate("Where is the hospital?", source="en")
print(res)           # Output: 'अस्पताल कतुक दूर छ?'
print(res.romanized) # Output: 'Aspataal katuk door chha?'

# 2. Universal pivot translation from French, Spanish, Japanese, etc.
res_fr = kumaoni.translate("Comment allez-vous?", source="fr")
print(res_fr)        # Output: 'कस छू तुम?'

# 3. Morphological verb conjugation
past_verb = kumaoni.conjugate("जाण", tense="past", person=1)
print(past_verb)     # Output: 'ग्यूँ' (I went)

# 4. Numbers to words & Devanagari numerals
words = kumaoni.num_to_words(108)
print(words)         # Output: 'एक सौ आठ'

# 5. Fast dictionary search
word = kumaoni.lookup("ईजा")
print(f"{word.kumaoni} means {word.english} ({word.hindi})")
# Output: 'ईजा means mother (माँ)'
