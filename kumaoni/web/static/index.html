अखाण (Traditional Kumaoni Proverbs)

गौंक जोगी जोगना, आन गौंक सिद्ध।
Gaunk jogi jogana, aan gaunk siddh.

Meaning: Familiarity breeds contempt; people rarely honor local talent.

Hindi Parallel: घर की मुर्गी दाल बराबर।

English Parallel: A prophet is never honored in his own country.

Developer SDK & Voice API Recipes

Build Voice AI assistants, speech synthesis apps, and translation bots with Python.

Python 3 • kumaoni_voice_app.py 
import kumaoni

# 1. Voice Translation with Phonetics & SSML
voice_res = kumaoni.voice_translate("Where is the nearest hospital?", source_lang="en")
print(voice_res.translated_text)  # 'पासक अस्पताल कसि छ?'
print(voice_res.romanized)        # 'Paasak aspataal kasi chha?'
print(voice_res.syllables)        # ['पा', 'स', 'क', 'अ', 'स्प', 'ता', 'ल', 'क', 'सि', 'छ']
print(voice_res.ssml)             # '<speak><prosody rate="0.95">...</speak>'

# 2. Pre-curated Mountain Voice Phrases
phrases = kumaoni.voice.phrases(category="emergency")
for p in phrases:
    print(f"[{p['category']}] {p['english']} -> {p['kumaoni']} ({p['roman']})")

# 3. Fast Morphological Conjugation & Lexicon
past_verb = kumaoni.conjugate("जाण", tense="past", person=1)
print(past_verb)  # 'ग्यूँ' (I went)
